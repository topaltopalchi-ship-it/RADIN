# Yoldash — منشی هوشمند اندروید

نسخهٔ اولیه: جست‌وجوی مخاطب با گفتار یا متن و تماس پس از تأیید کاربر.

## ساخت APK

این پروژه یک اپ بومی Android با Kotlin است. از GitHub Actions در بخش Actions می‌توان APK آزمایشی را ساخت و دریافت کرد.

## قابلیت‌ها
- جست‌وجوی مخاطب در فهرست مخاطبین گوشی
- تشخیص گفتار با سرویس گفتار اندروید
- نمایش شماره و تأیید تماس پیش از باز کردن شماره‌گیر

برای استفاده، مجوز مخاطبین و میکروفون را هنگام اجرا تأیید کنید. تماس فقط پس از تأیید کاربر به شماره‌گیر منتقل می‌شود.
